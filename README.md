# Haushaltsbestand v1.6.3 – Kategorien bearbeiten

Bitte auf GitHub diese 3 Dateien ersetzen:
- index.html
- app.js
- sw.js

Neu:
- Kategorien können unter „Haushalt → Wohnungen & Kategorien“ nachträglich bearbeitet werden.
- Änderbar sind:
  - Emoji
  - Kategoriename
  - optionale Beschreibung
- Der Standard-Karton 📦 bleibt nur der Fallback, wenn kein Emoji eingetragen wird.
- Eine Kategorienbeschreibung wird dezent angezeigt, wenn die Kategorie in „Bestand“ ausgewählt ist.
- Beschreibungen werden im Backup mitgesichert und wiederhergestellt.
- Alle Funktionen aus v1.6.2 bleiben enthalten.
